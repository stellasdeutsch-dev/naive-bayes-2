  1. Task: classify an all-chat message as toxic (T) or friendly (F).
  2. Features: x_j = 1 if word j appears (ez, noob, gg, wp), else 0.

The word “subject” is in every training email of both classes: θ̂ = 1. A new email without it gets 1 − 1 = 0 in both classes. “Crash and burn.”

This is the black swan paradox again: never having seen something does not mean it is impossible. The MLE overfits small counts. The fix is the same one you know from the Beta-Binomial and Dirichlet lectures: put a prior on every parameter.

remember it: with MLE, one zero count makes a whole class impossible. Priors keep every probability above zero.

Two tools we borrow

Beta prior for one probability

Prior θ ~ Beta(a, b). After k “yes” in n tries the posterior is Beta(a + k, b + n − k), and the chance of “yes” next time is its mean:

(k + a) / (n + a + b)

a = b = 1: (k + 1)/(n + 2), Laplace's rule. 0 of 3 → 1/5, never 0.

Dirichlet prior for class probabilities

Prior π ~ Dir(α₁, …, α_C). With class counts N_c the posterior is Dir(α_c + N_c), and the predictive class probability is:

(N_c + α_c) / (N + α₀),   α₀ = Σα_c

With two classes this is just a Beta again.

Bayesian naive Bayes

Factored prior: one Dirichlet for the class probabilities, and one independent Beta for every word and class:

p(θ) = Dir(π | α) · Πj Πc Beta(θ_jc | a, b)

Because each piece is conjugate, the posterior splits the same way, and each piece is “prior + counts”. To predict, plug in the posterior means instead of the MLEs (this is exactly the Bayesian posterior predictive):

θ̄_jc = (N_jc + a)/(N_c + a + b),   π̄_c = (N_c + α_c)/(N + α₀)

With a = b = 1 and α_c = 1 this is add-one (Laplace) smoothing: pretend you saw every word once present and once absent in every class.

Task 5(c): advantages of the Bayesian approach
  • No zero probabilities: unseen words or feature values never make a class impossible (zero-count / black swan problem).
  • Less overfitting with small data: the prior's pseudo-counts pull estimates towards sensible values.
  • Prior knowledge can be built in through a, b and α.
  • It gives a full posterior (uncertainty), and the predictive is just posterior means: as easy to compute as the MLE.

Mutual information

The question: which words actually help to tell toxic from friendly? Too many features make the NBC slow and let it overfit, so we want to keep only the useful ones (feature selection).

The tool: the mutual information between a feature X_j and the class Y measures how much knowing X_j tells you about Y:

I(X_j, Y) = Σx Σy p(x, y) log [ p(x, y) / (p(x) p(y)) ]

If X_j and Y are independent, p(x, y) = p(x)p(y), every log is log 1 = 0, and I = 0: the word tells you nothing. The more the joint differs from the product, the bigger I. In fact I(X, Y) is the KL divergence between p(x, y) and p(x)p(y), so it is always ≥ 0.

For a binary word, using the NBC's own numbers (θ_j = Σ_c π_c θ_jc is how often the word appears overall):

I_j = Σc π_c [ θ_jc log(θ_jc/θ_j) + (1 − θ_jc) log((1 − θ_jc)/(1 − θ_j)) ]

Irrelevant words & naive vs full model

When does a word not matter? (Week 6, Q2)

A word changes the posterior odds only through θ_1w/θ_2w (present) and (1 − θ_1w)/(1 − θ_2w) (absent). If θ_1w = θ_2w, both ratios are 1 and log 1 = 0: the word has no effect.

A smoothing side effect

Say “gl” is in every message of both classes, 4 toxic and 6 friendly. Add-one gives 5/6 ≈ 0.83 for toxic but 7/8 = 0.875 for friendly. The useless word now nudges towards the bigger class. Fixes: drop such words (stop words, MI filter), share one estimate across classes, or use a regularised discriminative model.

Naive vs full model (Week 6, Q1)

A full model of p(x | c) needs C(2D − 1) numbers; naive Bayes needs C·D. With little data NBC usually wins: more bias, much less variance, fewer zero counts. With lots of data the full model can win if the words really are dependent.

Task 1(h): explain mutual information

“I(X, Y) measures how far the joint distribution p(x, y) is from the product p(x)p(y), formally the KL divergence between them. It is zero if and only if X and Y are independent. In naive Bayes we compute I(X_j, Y) for every feature and the class; features with small I carry little information about the class and can be removed (feature selection).”

Why does the MLE naive Bayes break on unseen words?

θ̂_jc = 0 (or 1) makes one factor 0, so the whole class score is 0; if this happens in every class we get 0/0.

What priors does Bayesian naive Bayes use, and why those?

Beta(a, b) on each θ_jc and Dir(α) on π. They are conjugate to the Bernoulli and Categorical likelihoods, so the posterior is prior + counts.

What is add-one smoothing?

Predicting with posterior means under Beta(1, 1) and Dir(1, …, 1): θ̄ = (N_jc + 1)/(N_c + 2), π̄ = (N_c + 1)/(N + C).

What does mutual information measure, and how is it used?

How much a feature tells about the class: KL(p(x, y) ‖ p(x)p(y)). Rank features by it and keep the most informative ones.

When is the naive model better than the full model?

With little data: far fewer parameters (C·D instead of C(2D − 1)), so lower variance, even though the independence assumption adds bias.

4medium

When is MI zero?

Show with the binary MI formula that a word with θ_jT = θ_jF has I_j = 0.

hint

Then θ_j = Σ π_c θ_jc equals that same value.

solution
  • θ_jT = θ_jF = t ⇒ θ_j = π_T t + π_F t = t
  • Every log becomes log(t/t) = log((1 − t)/(1 − t)) = 0, so I_j = 0: the word is independent of the class
